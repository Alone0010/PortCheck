# PortCheck

A simple and modern port checking utility for Termux.

## Features

- Check a single TCP port
- Scan common ports
- Scan custom port ranges
- Fast parallel port scanning
- Scan history
- Clear scan history
- Clean and colorful terminal interface
- Lightweight and Termux-friendly

## Installation

```bash
git clone https://github.com/Alone0010/PortCheck.git
cd PortCheck
chmod +x install.sh
./install.sh
portcheck
```

## Menu

```text
[1] Check Port
[2] Common Ports
[3] Port Range
[4] Fast Scan
[5] Scan History
[6] Clear History
[0] Exit
```

## Usage

PortCheck is designed for quick TCP port checking and authorized network testing directly from Termux.

## Updating

```bash
cd ~/PortCheck
./update.sh
```
